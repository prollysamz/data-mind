    Model provider

    Data stays on this computer. Data Mind asks Ollama which models are installed and lets you choose one here.

    Start Ollama before refreshing. The list comes directly from /api/tags on your local Ollama service.

    With OpenRouter, your questions, the schema summary and the rows needed to answer are sent to OpenRouter and the model’s provider. Free models are rate limited, and some providers may log prompts.

    Create a key at OpenRouter. It is saved in plaintext on this computer in .datamind/settings.json (excluded from Git), never returned to the browser. Protect access to this file.

    All currently free text models are listed, including multimodal models that accept text. Native tool calling is recommended; other models use text tool compatibility mode. Availability and free-tier quotas depend on OpenRouter.

    Questions, schema context and required rows are sent to Google when this provider is active. Usage follows the quota and billing attached to your Google AI Studio project.

    Create a key in Google AI Studio. It is stored locally in the same gitignored settings file and is never returned by this page.

    Data Mind fetches the compatible Gemini models available to this key. If you only add a key, the first available model is selected automatically.
